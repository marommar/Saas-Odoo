Flujo de Datos (Workflow)

El sistema opera bajo un entorno de ejecución seguro (n8n). Cada solicitud entrante se procesa bajo el siguiente esquema:

1. Identificación Multi-Tenant

Extracción del tenant_id del payload para aislar entornos.

2. Recuperación de Entorno

Consulta a Supabase para recuperar la URL, BD y API Key específicos del cliente.

3. Ejecución Autónoma

El agente IA ejecuta herramientas dinámicas contra Odoo (ej. search_read sobre res.partner) y formula la respuesta final.

INFO [Agent] Incoming webhook triggered
INFO [Supabase] Fetching config for tenant_id: 1
INFO [Tool] Executing Validar_usuario_odoo
WARN [RPC] Requesting res.partner data
Payload response:
[ { "name": "Cliente Demo", "email": "demo@empresa.com", "category_id": [1, "Cliente Activo"] } ]

Preguntas Frecuentes

Resolvemos tus dudas sobre nuestra plataforma SaaS de integración.

Odoo Integrations es una plataforma SaaS cloud que permite a cualquier empresa conectar su ERP Odoo con modelos de Inteligencia Artificial. Facilita la creación de chatbots inteligentes capaces de consultar inventario, crear leads en el CRM y dar soporte a clientes en tiempo real, operando de forma online 24/7.
La seguridad es nuestra prioridad. Utilizamos arquitectura multi-tenant donde cada empresa opera en un entorno completamente aislado. Las credenciales de la API se almacenan cifradas en nuestra base de datos segura y la comunicación se realiza exclusivamente vía HTTPS.
No, nuestra solución SaaS está diseñada para ser "plug-and-play". Solo necesitas generar una API Key desde tu panel de Odoo, rellenar nuestro formulario de registro, y copiar el fragmento de código HTML en tu página web. Todo el procesamiento NLP se gestiona automáticamente en nuestros servidores.
